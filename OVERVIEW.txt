================================================================================
                         GETTING STARTED (3 STEPS)
================================================================================

STEP 1: SETUP (5 minutes)
--------------------------
Run the automated setup:
  > setup.bat

This installs all dependencies automatically.

STEP 2: PREPARE DATA & TRAIN (30 min - 4 hours)
------------------------------------------------
a) Create directories:
   > python utils.py --create-dirs

b) Add your dataset to data/raw/ folders:
   • data/raw/glioma/
   • data/raw/meningioma/
   • data/raw/pituitary/
   • data/raw/no_tumor/

c) Preprocess data:
   > python data_preprocessing.py

d) Train model:
   > python train.py

STEP 3: RUN APPLICATION (1 minute)
----------------------------------
Start the complete system:
  > start.bat

Access at:
  • Frontend: http://localhost:3000
  • Backend API: http://localhost:5000

API TESTING:
  # Health check
  > curl http://localhost:5000/api/health

================================================================================
                          CUSTOMIZATION
================================================================================

EASY TO CUSTOMIZE:

1. Change Model Architecture:
   Edit config.yaml → model.architecture
   Options: efficientnet-b4, resnet50, inception_v3

2. Adjust Training Parameters:
   Edit config.yaml → training section
   Modify: batch_size, epochs, learning_rate

3. Modify UI Design:
   Edit frontend/src/App.css
   Customize colors, fonts, layout

4. Add New Classes:
   Edit config.yaml → classes
   Retrain with new data

5. API Configuration:
   Edit config.yaml → api section
   Change: port, host, file limits
