================================================================================
                          🚀 HOW TO USE NOW
================================================================================

OPTION 1: Use Root Scripts (Easiest)
-------------------------------------
> setup.bat          # Setup everything
> verify.bat         # Verify installation
> start.bat          # Start all services

OPTION 2: Use Backend Scripts
------------------------------
> cd backend
> run_preprocessing.bat
> run_training.bat
> run_api.bat
> run_predict.bat --image test.jpg

OPTION 3: Run Directly
----------------------
Backend:
> cd backend
> python data_preprocessing.py
> python train.py
> python app.py
> python predict.py --image path/to/image.jpg

Frontend:
> cd frontend
> npm start
